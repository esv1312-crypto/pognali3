Карта «Погнали»

Изолированный тест — основное приложение не меняется

ТЕСТОВАЯ ВЕРСИЯ
Демонстрационные события нужны только для проверки карты. Нажми на маркер, попробуй фильтры и кнопку геолокации. Ничего не создаётся и не записывается в базу приложения.

Карта использует данные OpenStreetMap. Для промышленного запуска отдельно выберем поставщика тайлов с подходящими условиями использования.

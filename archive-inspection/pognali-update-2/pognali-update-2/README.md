### 11 — карта MapLibre 6.15.0 (`server/index.js`, `docs/telegram/index.html`, `package.json`)
Закрывает критическую уязвимость в версии 5 (в вашем коде она была недостижима, теперь её просто нет).
Версия 6 поставляется только как ES-модуль, поэтому страница подключает её через `<script type="module">`, а сервер отдаёт
`maplibre-gl.mjs`, его воркер `maplibre-gl-worker.mjs` и стили из одной папки `/vendor/maplibre-gl-6.15.0/`
(сжатие Brotli один раз при старте, кеш на год; в страницу добавлены `modulepreload` для быстрого старта).
Размер по сети: основной файл 240 КБ, воркер 121 КБ (раньше 247 КБ одним файлом).
Проверено: карта создаётся, стиль и WebGL работают, кластеры, зум по нажатию на кластер, всплывающие окна, повторное
использование карты при переключении «карта ↔ список», зум-кнопки; ошибок в консоли нет.
Требование: WebView с поддержкой ES-модулей (у Telegram это всегда так).

### 12 — постоянные интеграционные тесты (`test/api.integration.test.js`, `package.json`, `.github/workflows/telegram-api-test.yml`)

здоровье и подпись Telegram (нет, подделана, просрочена, верна); обновление имени профиля при кеше; кривой ввод даёт 4xx;

раздача статики (хеш-скрипт с `immutable`, ETag/304 у страницы, файлы карты, 404 на неизвестное).
Команды: `npm test` (все, около 7 с), `npm run test:unit` (без базы, `SKIP_DB_TESTS=1`).
В CI добавлены `test/**` в отслеживаемые пути и лимит 10 минут.

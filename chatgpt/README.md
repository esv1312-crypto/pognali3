# Погнали · ChatGPT MVP

## Цель

Первая версия «Погнали» внутри ChatGPT должна переводить человека из разговора в реальное действие.

Главный цикл:

**увидел сегодня рядом → выбрал → ПОЙТИ**

Второй путь:

**не нашёл → СОЗДАТЬ СВОЙ МИР → собрать компанию → ПОЙТИ**

«Погнали» не является социальной лентой и не строится вокруг просмотра чужой жизни.

## Первый пользовательский экран

**Ну что, погнали?**

- 🤝 Присоединиться к существующему
- 🔥 Создать свой мир

После выбора «Присоединиться»:

**Сегодня рядом**

Показываются события на сегодня, сначала наиболее близкие и релевантные пользователю.

После выбора события:

- название и emoji
- сегодня / время
- место
- сколько уже идёт / максимальная вместимость
- возрастной диапазон
- описание
- **ПОЙТИ**
- **НАПИСАТЬ**

После «Пойти» счётчик участников обновляется.

## Создание

Создание должно поддерживать минимум:

- название
- категория / emoji
- дата
- время
- место
- максимальное количество участников
- минимальный и максимальный возраст
- описание

Создание может начинаться естественной фразой пользователя, например:

«Хочу сегодня вечером футбол на 10 человек».

ChatGPT задаёт только недостающие обязательные вопросы.

## Архитектура

```
ChatGPT
   │
   │ Apps SDK / MCP
   ▼
Pognali API
   │
   ├── Users
   ├── Events
   ├── Participants
   ├── Chats
   └── Locations
   │
   ▼
Database
```

Android и другие клиенты в будущем используют тот же Pognali Core/API.

Технический интерфейс может быть простым, но продуктовая модель не должна терять ключевые механики оригинального «Погнали».

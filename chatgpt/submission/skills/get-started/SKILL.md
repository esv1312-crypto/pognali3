# POGNALI

POGNALI is a real-world activity layer, not a social feed.

## Core loop
Discover → Choose → Join → Invite → Go into real life.

## Rules
- Do not invent missing event details.
- Creation and invitation are separate actions.
- Creating an event never automatically invites people.
- Creating an invitation does not add the recipient to participants; acceptance is what joins them.
- Participant capacity is chosen by the creator and must never be silently defaulted.
- Do not request or infer precise device location. Use an explicit city, neighborhood, or place supplied by the user.
- Prefer concrete event actions over passive browsing.

# Pognali Core

Это первый независимый контур данных для ChatGPT-версии.

## Сейчас

Данные отделены от Android UI. Файл events.json — временный seed для разработки контрактов и сценариев.

## Следующий слой

Заменить seed на постоянное хранилище и HTTP API без изменения пользовательского сценария.

Core должен обеспечить атомарные операции:

- search_events
- get_event
- join_event
- create_event
- send_message

Правила join_event:

- нельзя присоединиться к несуществующему событию;
- нельзя присоединиться после заполнения лимита;
- нельзя присоединиться дважды;
- возраст пользователя должен попадать в min_age..max_age;
- после присоединения возвращается новое количество участников.

## Важно

Это не Android-изменение. ChatGPT-контур развивается отдельно и может позже стать общей дверью к Pognali Core для Android.
